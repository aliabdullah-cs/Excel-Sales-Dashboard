# Excel-Sales-Dashboard
**Project Overview**

This project showcases a dynamic Store Sales Annual Report Dashboard created in Microsoft Excel using:

Pivot Tables
Pivot Charts
Slicers
Interactive Filters
Data Visualization Techniques

The dashboard provides quick insights into store performance and customer behavior.

**Features**
📈 Sales vs Orders Analysis
Monthly comparison of:
Total Sales Amount
Number of Orders
👨‍👩‍👧 Men vs Women Sales
Gender-based sales contribution analysis.
📦 Order Status Tracking
Delivered
Cancelled
Returned
Refunded

🌍 Top 5 States by Sales
Identify the highest-performing states.
👥 Age vs Gender Analysis
Customer segmentation by:
Adult
Teenager
Senior

**🛒 Sales Channels Performance**
Comparison across platforms:
Amazon
Flipkart
Myntra
Ajio
Meesho
Nalli
Others

**Filter the dashboard dynamically by:**

Month
Channel
Category

**Tools & Technologies Used**
Microsoft Excel
Pivot Tables
Pivot Charts
Slicers
Data Cleaning
Dashboard Design

**Dashboard Insights**
Women customers contribute the majority of sales.
Most orders are successfully delivered.
Amazon and Myntra generate the highest order share.
Maharashtra and Karnataka are top-performing states.
Adult customers dominate purchases across both genders.
